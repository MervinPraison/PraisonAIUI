# Reference

> Reference for the aiui command line, the praisonaiui Python API, the YAML configuration, the REST endpoints and the protocols.

Look-up pages for every public surface. For a guided start, see the
[quick start](https://ui.praison.ai/docs/getting-started/quickstart.md).

| Surface | Page |
|---|---|
| The `aiui` command and its options | [CLI](https://ui.praison.ai/docs/api/cli.md) |
| `import praisonaiui as aiui`: callbacks, pages, styles, layouts, themes | [Python API](https://ui.praison.ai/docs/api/python.md) |
| `aiui.yaml` and the YAML app config | [YAML configuration](https://ui.praison.ai/docs/concepts/configuration.md) |
| UI components for server-driven pages | [Components](https://ui.praison.ai/docs/api/components.md) |
| Feature endpoints under `/api/*` | [Features REST API](https://ui.praison.ai/docs/api/features-api.md) |
| Chat sessions | [Sessions API](https://ui.praison.ai/docs/api/sessions.md) |
| Health and readiness | [Health API](https://ui.praison.ai/docs/api/health.md) |
| The optional TypeScript package | [TypeScript](https://ui.praison.ai/docs/typescript.md) |
| Feature protocols and versioning | [Feature protocols](https://ui.praison.ai/docs/features/protocols.md) |

App-shell plugins are written against `@aiui/sdk`; its exports are listed in
[UI plugins](https://ui.praison.ai/docs/features/plugins.md).
