# Architecture decisions

> Architecture decision records (ADRs) for PraisonAIUI.

Each record states the context, the decision and its consequences. The
numbered rules every pull request is reviewed against are in
[ARCHITECTURE.md](https://github.com/MervinPraison/PraisonAIUI/blob/main/ARCHITECTURE.md).

| Record | Decision | Status |
|---|---|---|
| [0001](https://ui.praison.ai/docs/adr/replay-view-clean-room.md) | The Replay view of recorded agent runs, a clean-room design | Accepted |
| [0002](https://ui.praison.ai/docs/adr/react-app-shell-and-plugin-sdk.md) | One React app shell and a plugin SDK, migrated from the vanilla dashboard step by step | Accepted |
| [0003](https://ui.praison.ai/docs/adr/selectable-layouts.md) | Selectable layouts as a first-party plugin kind | Accepted |
